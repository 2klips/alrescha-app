# ADR-003 — 전달 형태: GitHub-우선 웹 SaaS

- 날짜: 2026-08-09
- 상태: 채택 (Accepted)
- 정본: `spec/DECISIONS-ADR.md#adr-003--전달-형태-github-우선-웹-saas-2026-08-09`

## 맥락

로컬 CLI 설치와 workflow 설정은 솔로 바이브 코더의 온보딩 장벽이다. 결정론 우선 엔진은 서버 비용을 통제할 수 있고 웹 대시보드가 제품의 증거 그래프·영수증 비전과 맞는다.

## 결정

사용자 플로우는 **“GitHub에 푸시하면 자동 분석”**이다.

1. **수집:** GitHub App을 웹에서 한 번 연결한다. 푸시 webhook마다 서버가 문서와 코드 메타데이터를 스캔한다. 읽기 전용 최소 권한만 요청한다.
2. **분석 실행 위치:** SpecProof 서버다. 결정론 분석은 무료이며 AI 판단 단계만 크레딧 과금한다. BYOK를 지원한다.
3. **결과 표면:** 드리프트 발견, 문서 인벤토리, 증거 그래프, 영수증을 웹 대시보드에 표시한다.
4. **MCP:** 사용자별 토큰을 사용하는 호스티드 stateless MCP로 주문형 컨텍스트 팩과 발견을 제공한다.
5. **로컬 CLI:** 2단계로 연기한다.
6. **테스트 증거:** 서버는 테스트를 직접 실행하지 않는다. 분석 대상 커밋의 GitHub Actions JUnit/JSON 아티팩트와 체크런을 수집한다. 파싱된 실행 증거가 있을 때만 `verified`; 없으면 `inferred`로 강등한다.
7. **레포 쓰기:** MVP는 advisory-only다. 최소 인덱스도 사용자가 머지하는 PR 제안으로만 전달한다. 직접 쓰기와 자율 유지보수는 2단계다.

ADR-002에서 다음은 유지한다: 보증 리드 MVP, 주문형 로드, $20 앵커, MCP 2026-07-28 stateless, SKILL.md, in-toto형 영수증, 검증/추론 분리, 솔로 우선. 로컬 CLI 중심 전달 형태만 개정한다.

## 결과

- GitHub 이외 Git 제공자와 로컬 CLI는 MVP 범위 밖이다.
- 원본 코드는 분석 중 일시 fetch하고 영속 저장하지 않는다.
- GitHub 쓰기 호출은 advisory index PR 제안 모듈 밖에서 금지된다.
- CI 리포트가 없는 상태는 조용히 `verified` 처리하지 않고 `inferred`와 설명을 노출한다.
- 호스티드 MCP는 tenant-scoped token으로 인증하고 세션 상태를 만들지 않는다.
- 권한 철회와 webhook 검증 실패는 안전하게 강등되며 미검증 payload를 처리하지 않는다.
