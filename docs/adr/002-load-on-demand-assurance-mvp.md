# ADR-002 — 코어 설계·MVP 순서·가격

- 날짜: 2026-08-09
- 상태: 채택 (Accepted)
- 정본: `spec/DECISIONS-ADR.md#adr-002--코어-설계mvp-순서가격-2026-08-09-시장-재검증-반영`

## 맥락

정적 컨텍스트 파일은 성공률 개선 없이 비용을 늘릴 수 있다. 컨텍스트 허브 시장은 혼잡하지만 requirement→구현→테스트를 커밋 단위로 추적하는 보증 영역은 비어 있다. 제품은 주문형 컨텍스트와 증거 기반 보증을 결합해야 한다.

## 결정

### 1. 컨텍스트 코어는 주문형 로드(load-on-demand)

정적 컨텍스트 파일은 **최소 인덱스만** 유지하고 작업에 필요한 문서는 MCP로 그때그때 서빙한다.

- 자동 생성 문서를 항상-로드 컨텍스트에 넣지 않는다.
- LLM 생성 요약은 `inferred` 표시 후 주문형으로만 제공한다.
- 정적 파일에는 커스텀 빌드 명령, 도메인 제약, MCP 진입점처럼 비추론가능 정보만 둔다.

### 2. MVP는 보증(Spec-to-Proof) 리드

첫 데모 가치는 “머지된 코드가 스펙/문서와 어긋나면 플래그”다. 문서 인벤토리, 그래프, 컨텍스트 팩은 보증을 위한 기반 데이터 레이어이며 별도 제품으로 팔지 않는다. 배포·보안 스캔은 만들지 않는다.

### 3. 가격은 $20 앵커

- Free: 레포 1개, 크레딧 50/mo, 히스토리 30일.
- Pro: $20/mo, 무제한 레포와 공개 단가 기반 크레딧 및 무제한 히스토리.
- Team: 후속 단계.
- 실패한 실행에 과금 금지, 요금제 의미 중도 변경 금지, 추상 이중 단위 금지.

### 4. 표준 채택

- MCP **2026-07-28 stateless 스펙**으로 신규 구축한다.
- Sampling/Roots/Logging 사용 금지. 프로토콜 세션도 사용하지 않는다.
- Agent Plugins 1.0과 SKILL.md/`.agents/skills/`를 지원한다.
- AGENTS.md 정본과 Claude Code용 `@AGENTS.md` 래퍼를 사용한다.
- 영수증은 in-toto attestation 형태를 사용하며 자체 포맷을 발명하지 않는다.

## 결과

- 문서 본문이나 자동 요약을 AGENTS.md/CLAUDE.md에 인라인하는 경로는 금지된다.
- MCP 컨텍스트는 stateless 주문형 요청으로만 서빙한다.
- 결정론 분석은 무료이며 AI 판단만 예약·정산·환불 가능한 크레딧 작업이다.
- 실패 또는 스키마 불일치 AI 출력에는 과금하지 않는다.
- 측정 전 토큰 절감·성능 개선 수치를 주장하지 않는다.
- ADR-003이 전달 형태를 GitHub-우선 웹 SaaS로 개정하지만 본 ADR의 주문형 로드, 보증 리드, 가격 원칙, 표준은 유지한다.
