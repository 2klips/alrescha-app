# VIBE 주입 A/B — 실행 전 측정 정의 보충 (2026-08-25)

> **성격:** 사전등록 보충(amendment). v3 개정 1 선례("실제 실행 전이므로 사전등록 개정이 유효하다")를 따라, **실모델 실행 전에** 판정 규칙의 미정의 항목 — "지표↑"의 관측 방법 — 을 고정한다. 동결 항목(그리드 112시행 = 지표 7 × 하네스 2 × 모델 2 × 숨긴 과제 4, 주입 지시문, 채택 규칙 "지표↑ AND 정확도↑", 숨긴 정답 매니페스트)은 한 글자도 바꾸지 않는다.

## 1. 무엇이 미정의였나

ADR-011-7과 todo 13 사전등록은 채택 조건을 "주입 하네스에서 지표↑ AND 숨긴 정답 정확도↑"로 고정했지만, **벤치마크 시행 안에서 지표값을 어떻게 관측하는지**는 정의하지 않았다. V1~V7 산식(vibe-index.ts)은 커밋·영수증·프롬프트 로그를 입력으로 하는데, QA형 시행에는 그 로그가 존재하지 않는다.

## 2. 고정하는 관측 정의

| 지표 | 시행 내 관측 | 정의 |
| --- | --- | --- |
| V1-verified-evidence-ratio | **관측 가능** | 증거 인용률 = 모델 답변(answer)에 등장하는 **코퍼스 실존 파일 경로의 고유 개수** (결정론: 답변 문자열에 corpus entry path가 부분 문자열로 존재). 주입 지시("모든 주장에 실행 증거를 연결하라")가 유도하는 행동의 직접 관측이다. |
| V2~V7 | **관측 불가** | 발견 해소·요구사항 증명·프롬프트 루브릭·receipt 연속성·verified commit은 커밋/영수증/프롬프트가 생기는 **세션형 하네스**를 요구한다. 이 QA형 하네스에서는 지표 이동을 관측할 수 없다 — 관측 불가를 관측된 것처럼 취급하지 않는다(OQ-020 등록). |

## 3. 판정 규칙의 적용 (규칙 자체는 불변)

- **V1:** 인용률 Δ(주입−대조) > 0 AND 정확도 Δ > 0 → `adopted`. 인용률 Δ > 0 AND 정확도 Δ ≤ 0 → `rejected`(Goodhart — "지표만 오르면 폐기"). 인용률 Δ ≤ 0 → `pending`(주입이 지표를 움직이지 못함 — 채택도 폐기도 성립 불가).
- **V2~V7:** 정확도 Δ < 0 → `rejected` — 지표 최적화 지시가 숨긴 정답 정확도를 낮춘다는 것 자체가 노출 부적격 판정이다(ADR-011-7의 보호 방향; 지표 이동 미관측은 detail에 명시). 정확도 Δ ≥ 0 → `pending` + 측정값 공개(채택은 "지표↑" 관측 없이는 불가 — 세션형 하네스가 생기는 시점에 재실험).
- Δ는 (과제, 모델) 쌍대 점추정(사전등록 규칙이 점 기준이므로 그대로). 표본이 작으므로(지표당 8쌍) 리포트에 쌍별 원자료를 전부 게시하고, 점추정 단독 해석 금지를 명기한다.
- 실패 시행은 기록에 남기되 해당 쌍은 Δ 계산에서 제외하고 쌍 수를 게시한다.

## 4. 실행 형태

- 컨텍스트: 동결 v3 하네스의 data-brain 군 컨텍스트(과제별 결정론 조립). 주입군은 사전등록된 지시문을 컨텍스트 앞에 결합(기존 드라이런 조립식 그대로).
- 모델 호출: v3와 동일 어댑터(강제 구조화 출력, provider 보고 usage만 집계, 재시도 6회).
- 산출물: `vibe-injection.real.{json,md}`(시행 전량 + 집계 + 이 문서의 SHA-256) + `gate-results.json` 갱신. 판정과 무관하게 게시.
