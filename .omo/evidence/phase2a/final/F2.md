## 2. Unthemed-state sweep

The hex rule catches a colour written into a source file. It cannot catch a
screen that renders the *browser's* defaults because nobody ever wrote a rule
for it. `tests/e2e/screens-theme.spec.ts` covers that gap on 10 public routes —
dashboard, findings, lint, receipts, progress, harness, library, evidence
detail, onboarding, 404 — by asserting for each, in both themes:

- the set of painted colours **changes** when the stored theme flips (a screen
  that does not repaint has a hardcoded colour somewhere), and
- **no element** is left on the user agent's default `rgb(0, 0, 0)` text
  (`--text` is a near-white in dark and a near-black — `#20242E` — in light, so
  an exact match means a missing rule).

20 cases, all passing in the F1 runs. Screenshots in
`.omo/evidence/phase2a/task-8/`; they were regenerated in this wave and carry
the Wave 4 token corrections.

Two additional theme gates back this up: `tests/e2e/theme.spec.ts` verifies the
toggle, persistence across reload, first-visit `prefers-color-scheme`, and that
the boot script paints before hydration (no flash of the wrong theme).

Wave 4 added a fourth layer that the plan did not require but that closes the
remaining hole — `tests/design-tokens.test.ts`'s `token contrast` suite asserts
every text token clears AA on every surface in **both** themes, so a theme can
now fail for being illegible, not only for being unstyled.

## 3. String centralization

`tests/korean-strings.test.ts`, 37 cases, all passing.

- `PENDING_SCREENS` is **empty**. Every screen is in `CONVERTED_SCREENS`, where
  `findStrayLiterals` runs against it on every test run — 30 files including all
  of `/app/settings/*`, `/auth/*`, the graph UI and the dashboard.
- `every screen is classified as converted or pending` prevents a new screen
  from simply not being listed.
- `the detector actually fires on an inline literal` is the gate's self-test.
- Policy cases hold the copy contract itself: the modules carry the product
  copy, no untranslated English prose smuggles through, the conventional terms
  (Dashboard, Graph, Findings, Receipt, Data Brain, verified, inferred, MCP)
  stay English verbatim, and the headline surfaces are Korean.

Wave 4 touched user-facing markup once — the dashboard `h1` — and it passes:

```
 ✓ string centralization > apps/web/app/ui/dashboard-screen.tsx holds no stray user-facing literal
```

The repo name it now renders comes from the view model, not from a literal.
